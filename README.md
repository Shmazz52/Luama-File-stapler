# ◆ Luama — сшиватель файлов

Графическое приложение (Python + Tkinter) для объединения нескольких текстовых файлов (Lua, luau, txt, json, cfg, ini и др.) в один.

## Запуск
### Готовый exe (рекомендуется)
```
Luama.exe
```
Ничего устанавливать не нужно — полностью автономное приложение.

### Из исходников
Требуется Python 3 + Pillow (для узора и иконок).
```
python Luama.py
```

## Структура проекта
```
Luama.exe           — готовое приложение (двойной клик для запуска)
Luama.py            — исходный код
icon.ico / icon.png — иконка (контурная лама на ромбовом фоне)
llama_gui.png       — логотип для шапки GUI
make_icon.py        — скрипт генерации иконки
файл/               — ваши файлы (скрытая папка)
```

## Сборка exe заново
```bat
python -m PyInstaller --onefile --noconsole --icon=icon.ico --name Luama --clean --distpath . --workpath build --specpath build --add-data "llama_gui.png;." Luama.py
```
(иконку можно перегенерировать: `python make_icon.py`)

## Возможности
- **Форматы**: Lua, luau, txt, json, cfg, ini — маска расширений настраивается в поле «Маска»
- Добавление отдельных файлов (Ctrl+O) или целой папки (с учётом маски, рекурсивно)
- Управление порядком сшивки: вверх/вниз, инверсия, сортировка по имени, удаление дубликатов
- Список показывает размер файла; отсутствующие на диске помечены ✖
- **Клик по файлу** — просмотр его содержимого; кнопки «Открыть» (в системном редакторе) и «В папке» (проводник с выделением)
- **Проекты**: сохранение/загрузка списка и настроек в `.luama` (JSON)
- Опции сборки:
  - заголовки-комментарии `-- [1/2] имя_файла`
  - склейка модулей: удаление `module(...)` и `return M`
  - обёртка каждого файла в `do ... end` (изоляция локальных переменных)
  - минификация: удаление комментариев `--` и пустых строк
- Копирование результата в буфер обмена (Ctrl+B)
- Живой предпросмотр со статистикой: файлов / строк / КБ
- Горячие клавиши: Ctrl+O, Ctrl+S (сшить), Ctrl+P (предпросмотр), Ctrl+B, Delete
- Сохранение в один файл (UTF-8), поддержка чтения cp1251
- Тёмный визуал с ромбовым узором
